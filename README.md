# تطبيق أفق اليمن التعليمي (جاهز للتجهيز عبر الطريقة الثانية - APK / PWA)

يحتوي هذا الملف المضغوط على مشروع تطبيق **أفق اليمن التعليمي** متكاملاً وجاهزاً للرفع والتحويل المباشر إلى ملف **APK** عبر الطريقة الثانية:

## خطوات التحويل المباشر إلى ملف APK (الطريقة الثانية)
1. فك ضغط هذا الملف (`ufuq-yemen-education-app.zip`) لتجد الملفات التالية:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/icon-192.svg` و `icons/icon-512.svg`
2. ارفع هذه الملفات إلى أي استضافة مجانية فورية مثل **Netlify Drop** أو **GitHub Pages** أو **Vercel** لتحصل على رابط مباشر (`https://...`).
3. افتح موقع **PWABuilder.com** (أو **Median.co**)، وألصق رابط موقعك، ثم اختر **Package for Stores** -> **Android** لتوليد حزمة **APK** جاهزة للتحميل والتثبيت المباشر على جوالات أندرويد.
